# deepseek-harness :: dsh-notes-archived-testing

**Files in shard:** 119 (read: 119, skipped with reason: 0)
**What this shard covers:** the **archived `testing/` decision-record set** of the DeepSeek Harness "Agent Note" system, plus the archive's own index files. 39 English decision notes (2026-06-11 → 2026-09-28), their 39 Chinese translations, and 39 bilingual-pairing sidecar manifests form 39 *triplets*; `AGENTS.md` states the archival sealing rules and `manifest.json` is a 385 KB SHA-256 ledger of all 2 772 archived artifacts. Nothing here is code: this shard is the **rationale corpus** that explains how the harness made a nondeterministic LLM testable — record-once/replay-deterministic transcript snapshots, a model-visible header pin, a scripted wire-fault server, property-based tests for protocol-shaped code, and a long tail of "the test asserted the wrong state" post-mortems. Every note is a **decision record**: Problem → Decision → Alternatives considered → Consequences, with a `Status: implemented` line and an `Archived:` line.

Every file in the shard is `docs` or `generated-vendored`; **there is no Tier-1 source in this shard**, so §1 is one compact table per file class, and the analytical value sits in §2–§5.

The marker is a **machine-readable admission that the "Alternatives considered" section is missing** — the note is honest about its own gap instead of leaving a reviewer to guess.

### 1.3 Tier 2 — the 39 Chinese translations

Each `.zh.md` was read in full. Every one is a **complete, faithful translation** of its English partner: the same Problem → Decision → Alternatives considered → Consequences argument, the same `Status: implemented` / `Archived:` metadata, the same `agent-note-format:` marker where the English has one, and the same code identifiers, paths and numbers. Two systematic differences are worth recording:

- **Links are localised, not copied.** The Chinese side links to the *Chinese* target (e.g. `2026-06-11-property-based-testing.zh.md` links `../architecture/2026-06-11-runtime-arg-validation.zh.md`, and `2026-07-08-shared-acp-snapshot-package.zh.md` links `packages/support/remote-mock/README.zh.md` and `…#remote-proxy`). The English side links to the English target. A translation that copied the English link would break the pair.

## 2. Ideas worth stealing

1. **Commit a real recorded session as *both* the mock source and the expected output.** A hand-authored mock proves the harness can accept a shape; a harvested session log proves the product *produces* it. `2026-06-19-acp-snapshot-tests.md`. *(UNIQUE here; a convergence signal with the other two repos' replay work.)*
2. **Make the replay path structurally unable to reach a live provider.** "Replay mode skips `.env` loading, so a stray API key cannot trigger a live call." — a one-line property that removes an entire class of false-green. `2026-06-19-acp-snapshot-tests.md`.
3. **Assert two outputs when the product has two external surfaces.** stdout transcript *and* re-persisted session log, because "the surfaces are complementary". `2026-06-19-acp-snapshot-tests.md`.
4. **Pin the composed prompt and tool schemas in exactly ONE place per class, and make a live guard prove the pin covers everything.** A Markdown pin for the prompt, a JSON pin for the schemas, `"{{system}}"`/`"{{tools}}"` tokens in the fixture, and a uniformity guard that compares every live header (parent, spawn child, fork child, resume) against the reconstructed class sequence. `2026-07-06-pin-request-header-content-in-one-scenario.md`.
5. **Project the committed fixture; never slim the runtime log.** The durable JSONL keeps its `seq`/`time` envelope; the *reviewed* snapshot omits it so a diff describes behaviour, not storage mechanics. `2026-08-18-session-snapshot-envelope-projection.md`.
6. **Never run the golden-refresh mode in CI.** "Checking after writing turns the assertion mechanism into a generator." CI compares; a human refreshes. `2026-07-30-web-browser-snapshot-ci-gate.md`.
7. **Derive the plugin/roster list from the real source of truth; never copy it into the test package.** A generated static roster with a drift gate was rejected *after review* in favour of reading the bundles at import. `2026-09-06-client-assembly-test-line.md`.
8. **Make a missing default a hard failure at teardown.** `remoteDefaultResponses` "fails loud until" a row is added for a new boot-time call — the test suite refuses to pass while a product surface is unpinned. `2026-09-06-client-assembly-test-line.md`.
9. **Assert the settlement contract, not one winner of a race.** `2026-09-10-hosted-image-test-assumptions.md` (disposal race), `2026-09-08-ci-completion-observations.md` (barrier-controlled observations).
10. **A wait must be bound to the state it asserts, never to a wall-clock window or an earlier signal.** Stated as a rule and applied in three separate notes: `2026-09-08-ci-readiness-and-completion.md`, `2026-09-27-web-lane-assertions-name-their-input-state.md`, `2026-09-28-detail-close-waits-on-observed-state.md`. *(CONVERGENT within the repo; a strong signal.)*
11. **Prove the fix bites with a negative control.** Every late fix in the shard carries one: pin one clock and leave the other live; add a 25 ms delay in the effect; remove the close call; change a deny reason in a hook config. `2026-09-26-…`, `2026-09-28-…`, `2026-07-04-hook-snapshot-matrix.md`.
12. **Never collapse two renderings that state different facts into one normalized token.** The dated vs undated clock, the hovered vs unhovered row, the dated form in the Timing pane — collapsing deletes an assertion rather than stabilising it. `2026-09-26-web-conversation-clock-fixture-day.md`, `2026-09-27-web-lane-assertions-name-their-input-state.md`.
13. **Location decides test rigor.** The per-file coverage gate measures `packages/*/*/src` only, so example-local test machinery was *unmeasured*; moving it into a support package brought it under the gate. `2026-07-08-shared-acp-snapshot-package.md`.
14. **Do not write a guard that cannot fail.** A hook point that writes nothing to the transcript would produce an expected output byte-identical to the no-hook run — it is left on unit coverage and documented as a decision. `2026-07-04-hook-snapshot-matrix.md`.
15. **Report wire facts in the test double; never let it classify retryability.** The fault server says "socket reset", "clean EOF", "partial reset"; the product's retry policy decides what is retried. `2026-07-25-scriptable-llm-wire-fault-server.md`.
16. **Make random fault injection reproducible with a logged seed, and say the weights are test pressure, not incident statistics.** `2026-07-25-scriptable-llm-wire-fault-server.md`.
17. **A "value the OS owns" is not guaranteed to come back as written.** Write it back only where the assertion tolerates the write-back failing; otherwise take the expected value from a fresh read. `2026-08-28-ci-test-reliability-skill.md`.
18. **Budgets and retries are not masking fixes; a granted budget must not be restored.** `2026-08-28-ci-test-reliability-skill.md`, `2026-08-27-translation-pairing-merge-budget.md`, `2026-08-29-windows-lane-hook-and-lefthook-budget.md`.
19. **One env var governs one budget, including the hook budget.** Setup and teardown pay the same contention the case budget accounts for. `2026-08-29-windows-lane-hook-and-lefthook-budget.md`.
20. **Reuse the release builder as the merge-blocking contract, with no path filters.** A required PR job that calls the *same* builder the release workflow calls. `2026-08-12-required-python-runtime-pull-request-ci.md`.
21. **Property-test the protocol-shaped code with realistic-but-adversarial generators, print the seed, keep it under 10 s.** It found a real duplicate-block bug on its first run. `2026-06-11-property-based-testing.md`.
22. **A machine-checked bilingual lock.** Both languages carry equal authority; a sidecar records both blob hashes; a verifier re-records the pair. `docs/i18n/README.md` as cited by every sidecar.
23. **A frozen clock is not a pinned clock.** Re-apply the anchored instant on an interval, because two product holds compute elapsed time from two reads of `Date.now()`. `2026-09-26-web-conversation-clock-fixture-day.md`.
24. **Serialize the derived-vs-copied decision at the package boundary.** "Explicit > implicit at package boundaries" — persist the fact the producer already knows rather than re-deriving it in the reader. `2026-06-22-fork-child-replay-seed-boundary.md`.

## 3. Trading-specific findings

This shard is entirely a **test-decision corpus**; it contains no scheduling, no broker integration, no post-mortem loop and no trade log. Stated plainly, per the brief:

- **Long-lived monitoring & scheduled work:** *not in this shard* — the archive's `process/`, `feature/` and `automation`-adjacent notes are other shards. The nearest transferable fact is the **bounded retry** discipline for a transient external stall (`2026-09-06-python-runtime-install-retry.md`): retry a transient external dependency a bounded number of times with a pause, and let a deterministic defect still fail after the budget.
- **Human-in-the-loop approval:** *not in this shard* as an approval product, but two mechanisms transfer directly. (a) The **hook matrix** (`2026-07-04-hook-snapshot-matrix.md`) models an external decision gate that *denies* or *blocks* a tool call and whose outcome is written into the durable transcript as `hook/*` events — an approval trail that survives in the session log rather than in a UI. (b) The **declarative `permissionAnswers` FIFO keyed by option *kind*** (`2026-07-08-shared-acp-snapshot-package.md`) is the exact shape a "Log this trade / reject / request changes" approval needs: a scripted queue of human decisions, addressed by a stable vocabulary rather than by ids the agent issues at random, where an absent answer degrades to `cancelled` and an impossible answer fails the run rather than being absorbed as an agent-side denial.
- **Post-mortem / reflection loops:** *not in this shard*. The transferable pattern is the **post-mortem-as-committed-document** form: the shard cites `docs/postmortem/0001-acp-default-export-drops-inject.md` (`2026-06-19-acp-snapshot-tests.md`) as the incident that motivated the whole snapshot tier — a defect file that names a product defect and becomes the reason a gate exists. August Trading's `docs/plan/full-audit.md` + `open-items.md` already has this shape.
- **Multi-agent:** *partially in this shard*, and the answer is sharp: **debate is not the mechanism — routing is.** `2026-06-22-subagent-snapshot-replay.md` shows the failure mode (a global cursor hands a child the parent's script) and the fix (key the replay by *who calls*). The value of a subagent is that it has its **own session and its own script**; a child that inherits a parent's prefix needs the boundary persisted so the parent is not replayed as the child (`2026-06-22-fork-child-replay-seed-boundary.md`). For August Trading's bot roster / group rounds this says: a subagent's value is its *isolated context*, and any "debate" that shares one context is not a subagent at all.
- **Structured logs the model can query:** *not directly in this shard*, but the **session JSONL as the durable, model-queryable record** is defined here: one physical row per durable event, `assistant/message` / `assistant/attempt` streams, tool/message/boundary events, a versioned header, and a projection rule for the reviewed copy (`2026-06-19-acp-snapshot-tests.md`, `2026-08-18-session-snapshot-envelope-projection.md`). August Trading's trade journal is the analogue; the two transferable rules are (a) **one physical row per durable event**, and (b) **the reviewed copy is a projection, the durable copy keeps the envelope**.
- **Staying simple as features accumulate:** the shard's strongest simplicity levers are all *subtractive*: delete the redundant `session.expected.jsonl` (`2026-06-20-…`), delete the two dead `.env` parsers (`2026-07-26-…`), delete the per-case constant that restated a describe value (`2026-08-29-…`), delete the twin config file (`2026-07-04-single-source-…`), and **decline to snapshot three hook points** (`2026-07-04-hook-snapshot-matrix.md`).

## 4. Non-obvious decisions and gotchas

1. **The archived notes are explicitly *not* current authority.** `.agents/notes/archived/AGENTS.md` says so in the first line, and forbids even *inspecting* links out of archived notes. A reader who treats these as current spec will misread several of them (e.g. `2026-07-18-tui-terminal-state-snapshots.md` describes an application suite that was later **deleted**, and `2026-08-24-session-log-snapshot-corpus.md` — cited by several notes — is **not in this shard**).
2. **A `describe`-level Vitest timeout OVERRIDES the runner's `--testTimeout` flag; it does not defer to it.** This single fact caused two of the shard's notes (`2026-08-27-…`, `2026-08-29-…`) and is stated as a general rule in the reliability skill.
3. **A committed session snapshot is NOT valid persistence JSONL.** `2026-08-18-…` omits `seq`/`time`/`seq0`/`time0`; replay consumers must go through `parseSessionLog`, which assigns the missing fields in memory.
4. **Normalization is per-side, not shared.** `2026-06-20-…`: `normalizeSessionLog` scrubs cwd by *exact string match*, so a shared context would leave the fixture's recorded cwd surviving and fail every compare. Each side normalizes against its own header-derived context.
5. **Replay is positional ⇒ exactly one in-flight model stream per scenario.** More live sessions than recorded scripts is a *fail-loud* error ("an unrecorded subagent appeared"), never a silent mis-route. Concurrent-session snapshots need request-keyed entries — not shipped.
6. **A fork child's log starts with the parent's events.** Anything that derives a child's script from "the whole log" replays the parent as the child. The cut must be persisted explicitly (`isSeeded` + `inheritedEventCount`), never inferred from `seed.length` — a *resume* seeds with the whole stored log.
7. **`session.jsonl` and `stdout.expected.jsonl` are not redundant.** The stdout artifact is the editor-facing automation wire; the session log is the loop/persistence behaviour. The wire intentionally omits what the log records.
8. **A missing hook config file is a silent no-op by design** — a bridge that cannot read its config registers nothing, so a project that ships only one dialect's file is unaffected. `2026-07-04-hook-snapshot-matrix.md`.
9. **`connection_refused` cannot be produced by a bound request handler** — it is a CLI listener-lifecycle phase in the fault server. `2026-07-25-…`.
10. **A fault server that classifies retryability would be testing the mock, not the product.** The shard's server deliberately reports wire facts only; the retry policy is exercised through the real adapter. `2026-07-25-…`.
11. **A permanently frozen clock silently disables every elapsed-time hold in the page.** Two product features (a 150 ms title hold, a 10 ms composition guard) compute `Date.now() - previousReading`; a frozen clock never advances it. `2026-09-26-…`.
12. **`findByText` resolving is not the same commit as the panel closing.** The close is a *post-commit effect* by design, so the assertion must be a `waitFor` on the asserted DOM. `2026-09-28-…`.
13. **The two SDKs are independent projections of one agent loop.** A change to the loop, session lifecycle or `SessionEventMap` must update *both* expected outputs, not just the one a contributor happens to run. `2026-08-13-…`.
14. **`execa`'s result fields are independent** — `stdout`, `stderr`, `exitCode`, `signal`, `timedOut`, `failed` — matching the repo's rule to report orthogonal subprocess outcomes separately. `2026-07-26-…`.
15. **Two notes carry a machine-readable admission of their own format gap**: `<!-- agent-note-format: alternatives-not-recorded (pre-format Agent Note) -->`.
16. **One sidecar's re-record path is stale**: `2026-08-12-required-python-runtime-pull-request-ci.i18n.yaml` still points at `.agents/notes/implemented/…`, the pre-archive location — a small, real inconsistency left by the archival move.
17. **Some sidecars omit the file argument** in their re-record command (`--write` with no path) while most include it — the command is not uniform across the 39.
18. **The bilingual sidecar pins content, not structure.** Five of the 39 Chinese files translate the body but keep the English section headings, and the translated heading vocabulary varies across the other 34 (`决策`/`决定`, `曾考虑的替代方案`/`考虑过的替代方案`/`备选方案`/`已考虑的替代方案`, `后果`/`影响`). A content-hash pairing verifier cannot see this, so "the pair is in sync" does not mean "the pair is structured identically".
19. **The Chinese side localises its links** (`.zh.md` targets, and even `README.zh.md#anchor`), while the English side links to the English target. A translation that copied the English link would silently break the pair, and the blob-hash check would only notice the next time the English side moved.
20. **The archive's own manifest is the only thing that knows the sealed set.** `manifest.json` carries 2 772 SHA-256 entries; the `AGENTS.md` says the normal verifier "rejects changed or missing sealed artifacts, incomplete triplets, unknown kind folders, and invalid archive metadata", and the archival procedure itself is allowed to touch exactly four things (relocate the triplet, insert the `Archived:` line below both `Status:` lines, re-record the sidecar, repair inbound links) — with a named exception list in `scripts/archived-agent-notes.ts` for one Figma-link removal.

## 5. Weak spots

1. **The archive is a snapshot of a decision corpus, not of the code.** Several notes are explicitly superseded — the ACP snapshot tier's fixture ownership was "superseded" by a later session-log-corpus decision (`2026-06-19-…`), the TUI application suite was **deleted** (`2026-07-18-…`), and the reliability skill note says it "does not audit or rewrite the current test corpus". A reader who mines this shard for current architecture will mine a moving target unless they follow the supersession links — and several of those links point outside this shard.
2. **The shard is one *kind* of decision, and there are 924 en.md / 924 zh.md / 924 i18n.yaml artefacts behind it.** The tripling is deliberate (bilingual equality is a real constraint) but it means the corpus is ~3× larger in bytes than its decision content, and a reader pays full price for the translation. The pairing sidecar is the only place the duplication is justified — and one of them still names a stale path.
3. **The failure taxonomy is heavily weighted to CI-host contention**, not to product defects. Five of the last ten notes are about a suite timing out on a shared Windows volume or a hosted macOS runner. Each is honest, and each trade is explicitly costed ("a real slowdown from hundreds of ms to tens of seconds now passes where the previous ceiling would have caught it"), but the cumulative effect is that a meaningful slice of the corpus is about *the machine*, and the archived copy is where it will be looked up.
